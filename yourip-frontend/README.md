# YouRip interface

This directory contains the Next.js interface. Run `npm start` from the **repository root** (the parent of this folder) to start the complete application.

See the [project README](../README.md) for prerequisites, setup, troubleshooting, and development commands.

## Demo build

`npm run dev:demo` and `npm run build:demo` run the simulated, static demo (no backend). See [../docs/vercel-demo.md](../docs/vercel-demo.md).
